# Hero images

Drop files in here using these exact names and the homepage hero will pick
them up automatically — no code changes needed. Until a file exists, the
hero shows a placeholder in its place.

| File | Used for | Recommended size |
| --- | --- | --- |
| `student.png` | Main hero photo (student, transparent/cutout background) | ~1000×1300, PNG with transparency |
| `mentor.jpg` | "Become a Mentor" card headshot | ~200×200, square |
| `avatar-1.jpg` | Trust row avatar 1 | ~100×100, square |
| `avatar-2.jpg` | Trust row avatar 2 | ~100×100, square |
| `avatar-3.jpg` | Trust row avatar 3 | ~100×100, square |

The main student photo works best as a cutout (no background) so it sits
naturally over the green blob illustration behind it.
